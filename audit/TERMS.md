# Terms coverage and review record

Reviewed on 2026-11-04. **159 entries, 203 source descriptions, 13 topics, and 10 separate clarification notes.**

The glossary is an independent, manually curated set of source quotations. It was not generated by treating MCQ answers or distractors as definitions. All 131 PDF pages were rendered and inspected, including image-only slides, comparison tables, formulas, and notation. Windows OCR helped locate text; its output was corrected against the rendered pages and was not accepted as verbatim evidence by itself.

Descriptions preserve wording, spelling, punctuation and meaningful list structure. Artificial line wrapping/spacing is reflowed. Mathematical fractions/subscripts are expressed as readable linear text. Native ligature glyphs are represented by their ordinary letters. Identical teaching points are combined; different descriptions are retained as labeled versions. Related-topic filters can expose a canonical entry without duplicating it in the All topics list.

## Verification

`npm run audit:terms` checks every description citation with usable selectable text: **47 references match the source PDFs**, ignoring whitespace and ligature encoding only. The other **156 description references are image-based** and have the recorded visual review. This is separate from the structural content/UI tests; a successful extraction check is not proof of methodological correctness.

Application checks validate IDs/topics, unique entries/definitions, sources/pages, all 131 inventory records, exact-wording regression cases, inert rendering, search/filter combinations, session restoration, practice isolation, and unavailable storage. Browser checks cover desktop/mobile themes, normal and enlarged text, history, downloads, local table scrolling, and direct-file operation. See [the verification record](VALIDATION.md) for final check totals.

Testing uses isolated headless Chrome, not physical iOS/Android devices or assistive-technology certification. No backend, runtime AI, glossary scoring, or extra progress storage was added.
